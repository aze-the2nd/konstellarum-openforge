- ein Tool in python als stand-alone
- zum erfassen von verschiedenen Aufgaben bzw. zum stempeln von Projektzeit
- eine grafische Oberfläche 
- Tasks=Todos sollen erstellt werden können
- Tasks sollen "angestempelt" werden können
	- anschließend soll ein Timer laufen der die Projektzeit zählt
	- wenn eine andere Task angestempelt wird soll die vorherige Task gestoppt werden und die Zeit gespeichert
	- immer nur eine Task soll aktiv sein

- export-funktion als csv
- es soll pinnbar sein (toggle)


- Das Qt-Subprojekt lebt künftig unter `taskclock_qt/` und wird vom Projektbaum mitgeführt.
