# Phronesis

## Zweck
Eine kleine Android-App, die GitHub Releases als Update-Quelle nutzt und beim Start automatisch prüft, ob eine neuere Version verfügbar ist.

## MVP
- App startet als Android-App mit Compose-UI
- Update-Check beim Start gegen GitHub Releases
- Update-Hinweis in der App
- Download und Installation direkt aus der App
- App öffnet sich nach erfolgreichem Update erneut

## Update-Quelle
- GitHub Releases im Repo `aze-the2nd/blackforest-openforge`
- Tag-Muster: `phronesis-vX.Y.Z`
- Asset-Muster: `Phronesis-vX.Y.Z.apk`

## Nicht im ersten Schritt
- Play Store / Play In-App Updates
- Accounts / Login
- Analytics
